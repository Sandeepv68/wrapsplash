# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :white_check_mark: |
| 4.0.x   | :x:                |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within WrapSplash, please send an email to Sandeep Vattapparambil via [GitHub](https://github.com/SandeepVattapparambil). All security vulnerabilities will be promptly addressed.
